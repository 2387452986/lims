# 功能清单

## 流程工作台

- 按当前账号权限展示快捷入口、业务阶段数量、待办和预警。
- 待派发、我的检测、待复核、待审核、待签发、待发放和到期应检均可跳转到带真实筛选条件的目标页面。
- 近期动态和站内通知来自业务事件与审计投影，不使用静态卡片数据。

## 基础数据

- 人员信息、账号绑定、角色、部门、职称、资格、培训、项目组和检测能力。
- 单位主体、负责人、办公地址版本、机构资质、计量资质和电子签章就绪状态。
- 检测目录树、项目修订、参数、字段、公式、依据、标准、价格、样品配置、模板控制和编号规则。
- 数据字典、货架层级、人工可读样品标记、受控文档版本、消息规则和操作日志。

## 设备物质

- 设备主档、型号、编号、位置、保管人、状态和有效期。
- 检定/校准证书、送检、借用、归还、使用、校准、入库、出库和预警。
- 试验提交自动生成设备使用记录；并发操作和开放中业务由数据库约束防止重复。

## 检测业务

- 工程、客户、联系人、预委托、正式委托和委托变更。
- 委托从检测目录选择项目与参数；受理冻结项目修订、参数修订、样品组和模板控制快照。
- 样品接收、拆分、交接、留样、消耗、返还和处理。
- 任务创建、分配、接收、拒绝、退回、改派、开始和完成。
- 原始记录草稿、提交、独立复核、退回、复测和受控数据修改申请。

## 报告与签章

- 报告编制、审核、退回、签发、人员签名、机构章和固定渲染器 PDF。
- 发放、签收、下载授权、打印、归档、作废和 `R1/R2` 修订。
- 签发版本、签章位置和归档包不可变；高风险动作执行近期密码复核。

## 质量与台账

- 样品、试验、报告、混凝土、现场检测和到期业务台账。
- 不合格、质量例外、处置措施、责任人提交、独立验证和关闭。
- CAPA 未完成时阻断受影响报告；质量动作和证据链写入审计。
- 阶段汇总、综合报告、强度评定和预警投影。

## 合同财务与外部边界

- 合同、价格模板、费用、收款、退款和付款的受控状态流程。
- 现场物联、支付和监管适配器提供配置检查、权限和受控禁用态；没有协议或沙箱时不生成伪造结果。

## 系统治理

- 菜单/动作权限、机构/部门/本人/项目数据范围、敏感字段、导出、打印、下载与签章权限。
- RFC Problem Details、请求 ID、字段错误、阻塞原因、幂等重放和 HTTP 409 乐观锁冲突。
- PostgreSQL 后台作业承载大型导入、导出与 PDF；失败、重试、锁和结果下载均可追踪。

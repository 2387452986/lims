# 供应商系统迁移与切换方案

## 输入契约

供应商必须提供 UTF-8 结构化数据包、字段字典、状态对照表、附件清单及每个附件 SHA-256。不接受截图、页面爬取或直接连接供应商生产库作为正式迁移通道。

一期仅迁移：

- 机构、部门、人员、资格、客户、工程、检测参数、设备及有效证书。
- 截止时点仍在途的委托、样品、任务和质量问题。
- 历史报告及附件作为只读档案，保留原编号、原状态、原时间和来源标记。

## 两次强制预演

1. 预演一：字段/状态映射、缺失值、重复编号、无主附件和非法文件的全量清洗。
2. 预演二：使用拟定生产配置和完整附件执行，记录导入时间、资源峰值、失败清单和回滚时间。

每次预演必须对账：源/目标行数、业务编号唯一性、状态数量、外键完整性、附件数量/SHA-256/字节数，并对每类数据抽样至少 30 条进行业务人员签字。

## 正式切换

- 冻结旧系统写入，记录冻结时点和最终编号。
- 导出最终增量，验证签名/哈希，以幂等批次导入。
- 重跑全部对账和抽样，生成不可修改的迁移报告。
- 创建切换前成对备份，部署、冒烟、业务签字后切换内网 DNS。
- 维护窗口超时、关键对账不一致或核心闭环冒烟失败时，立即恢复旧系统写入并取消 DNS 切换。

## 当前外部阻塞

供应商结构化导出包、附件清单、生产内网域名/CA、生产主机、独立备份目标和 `docs/formal-materials` 尚未提供，因此迁移预演与生产切换不得标记为通过。

# 生产就绪门禁

## 仓库内已落地

- 模块化单体、Flyway 前进迁移、安全会话、动作/数据范围、乐观锁、幂等、RFC Problem Details 和不可变审计。
- 委托→样品→任务→试验→审核→签发→签章→发放→签收→归档闭环。
- CAPA、质量例外、数据修改、R1/R2 报告版本链和每版本独立归档。
- PostgreSQL 作业表、PDF worker、SHA-256 不可变文件卷、成对备份/恢复脚本、Prometheus 规则和 Grafana 面板。
- GitLab 编译、单元/集成/Chromium、OpenAPI、SBOM、Trivy 源码/镜像、受保护标签和人工生产批准作业。

## `1.0.0` 不可跳过的外部门禁

- 受保护发布标签必须匹配 `1.x.x`，CI 全绿且生产作业获得明确人工批准。
- 内部 CA 证书、DNS 域名、主机清单、秘密和异机备份目标在 Git 外安装并复核。
- PostgreSQL dump 和不可变文件快照共享一个 recovery point，SHA-256 校验通过。
- 季度恢复演练实测 RPO≤1 小时、RTO≤4 小时。
- 使用正式资料完成检测参数、公式、原始记录和报告模板的业务签字。
- 供应商迁移包至少两次预演，行数、编号、状态、附件哈希和抽样结果一致。
- 30 项追踪矩阵、性能、安全、Chromium 和 Product Design QA 全部通过。
